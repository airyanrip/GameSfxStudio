# GameSfxStudio

게임 효과음(전투·UI·마법·가챠 연출 등)을 **만들고, 다듬고, 프로젝트별로 저장·내보내는** Windows용 로컬 프로그램입니다.
인터넷 계정 없이 내 PC에서만 동작하며, 소리를 만드는 방법이 세 가지이고 **한 소리 안에서 섞어 쓸 수 있습니다**(영화 사운드 디자인의 레이어링).

| 방법 | 특징 | 추가로 필요한 것 |
|---|---|---|
| 🎛️ **합성** (기본) | 프리셋 36종 + 슬라이더. 즉시 반응, 재현 가능 | **없음** |
| 🎓 **참고 음원 학습** | 가진 소리를 분석해 닮은 합성 소리를 자동으로 맞춤, 원본 조각을 레이어로 겹치기 | 사용 권한이 있는 음원 |
| 🤖 **AI 생성** | 문장으로 실제 녹음 같은 소리 생성 (모델 2종 선택) | AI 엔진 + 모델 (**앱이 물어보고 자동 설치**) |

## 📋 필요한 프로그램 (전부)

| 프로그램 | 언제 필요? | 설치 방법 |
|---|---|---|
| **Windows 10/11 (64비트)** | 항상 | — |
| **Microsoft Edge** | 항상 (화면 표시) | Windows에 **기본 내장**. 없으면 기본 브라우저로 열립니다 |
| **GameSfxStudio.exe** | exe로 실행할 때 | [Releases](../../releases)에서 다운로드. **Python 불필요** |
| **Python 3.11 또는 3.12** | 소스로 실행할 때 / **AI 엔진** 설치할 때 | **자동 설치 지원** — 없으면 `run.bat`/설치 도우미가 **먼저 물어보고**, 동의하면 python.org 공식 파일을 받아 **디지털 서명을 검증한 뒤** 내 사용자 폴더에만 설치합니다(관리자 권한·PATH 변경 없음) |
| **NVIDIA 그래픽카드 + 드라이버** | AI 생성을 **빠르게** 쓰려면 (VRAM 4GB 이상 권장) | ⚠ **자동 설치 불가** — [nvidia.com/drivers](https://www.nvidia.com/drivers). 없으면 CPU로도 되지만 소리 하나에 수 분 걸립니다 |
| **PyTorch 2.6.0** + diffusers·transformers 등 (약 3~4GB) | AI 생성 | **자동 설치** (설치 도우미). GPU가 있으면 CUDA 12.4판, 없으면 CPU판 |
| **AI 모델** 1~2개 (각 약 5GB) | AI 생성 | **자동 다운로드** (설정 › AI 모델). 아래 표 참고 |
| **Git** | 소스를 `git clone` 할 때만 | [git-scm.com](https://git-scm.com/download/win) — ZIP으로 받으면 불필요 |

**디스크 여유 공간**: 기본 기능 약 0.1GB · AI 엔진 약 6GB · 모델까지 모두 받으면 약 **11GB**.
**AI를 쓰지 않으면** 위 표에서 Python 이하는 전부 필요 없습니다.

## 🚀 설치와 실행

### A. exe로 실행 (권장 — 설치 없음)
1. [Releases](../../releases)에서 `GameSfxStudio.exe`를 받아 **경로가 짧은 폴더**(예: `C:\GameSfxStudio`)에 넣습니다. ⚠ 폴더가 너무 깊으면 AI 엔진을 설치할 수 없습니다(아래 문제 해결).
2. `GameSfxStudio.exe`를 더블클릭합니다. 주소창 없는 프로그램 창이 열립니다.
3. **처음 실행하면 `처음 설치 도우미`가 자동으로 뜹니다** → 아래 참고. 콘솔 창을 닫으면 완전히 종료됩니다.

### B. 소스로 실행
```
git clone <이 저장소 주소>
cd GameSfxStudio
run.bat
```
`run.bat`이 Python을 찾고, **없으면 설치할지 물어본 뒤**(Y/N), 앱 전용 환경(`.venv`)을 만들고 필요한 패키지를 설치하고 앱을 실행합니다.
Python이 다른 곳에 있다면 `set GAMESFX_PYTHON=C:\경로\python.exe` 후 `run.bat`.

### 🧰 처음 설치 도우미 (첫 실행 때 자동으로 열림)
- **아무것도 설치하지 않고 닫아도 됩니다.** 합성·저장·내보내기·참고 음원 학습은 그대로 씁니다. 나중에 `설정 › 설치 도우미`에서 다시 열 수 있습니다.
- 보여주는 것: NVIDIA GPU 감지 · Python 상태 · 디스크 여유 · AI 엔진 설치 여부
- **`AI 엔진 설치`를 누르면** 무엇을 설치하는지(Python 여부, 가상환경, PyTorch, 라이브러리)와 용량을 **확인 창**에 보여주고, 동의해야만 시작합니다. 진행 단계·실시간 로그가 보이고 **언제든 취소**할 수 있습니다(약 5분~20분, 인터넷 속도에 따라).
- 안전 장치: Python 설치 파일은 **PSF 디지털 서명을 검증**하고, 이미 있는 Python·다른 프로젝트의 환경은 건드리지 않으며, 관리자 권한을 요구하지 않습니다.
- 명령줄로 하고 싶다면: `engine\sao\setup_ai.bat`

### 🩺 문제 해결
| 증상 | 원인 / 해결 |
|---|---|
| 설치 도우미가 **"프로그램 폴더 경로가 너무 깁니다"** | Windows 경로 길이 제한(260자) 때문입니다. 프로그램 폴더를 `C:\GameSfxStudio` 처럼 **짧은 경로로 옮긴 뒤** 다시 실행하세요(또는 Windows '긴 경로 사용' 설정을 켜기) |
| "NVIDIA GPU를 찾지 못했습니다" | 드라이버가 없거나 NVIDIA 카드가 아닙니다. CPU로 설치·실행은 되지만 매우 느립니다 |
| 모델 다운로드 **401/403** | 토큰이 Read 토큰인지, 모델 페이지에서 **라이선스에 동의**했는지 확인 |
| Python 설치 실패 | 로그의 메시지를 확인하거나 python.org에서 3.11을 직접 설치한 뒤 다시 시도 |
| 설치가 도중에 멈춤 | `취소` 후 `다시 시도` — 이미 받은 것은 재사용합니다 |
| 소리가 안 남 | `설정 › 미리듣기 볼륨` 확인 |

## 사용 흐름
1. **효과음 작업실** — 프리셋 클릭(🎬 고퀄리티 16 · 🕹️ 레트로 20 · ⭐ 내 프리셋), 또는 `권총 총소리`, `큰 폭발음`, `heavy sword swing`처럼 **설명을 적어** 시작. 파형·스펙트로그램을 보며 재생(Space), 레이어별 슬라이더로 다듬기(이름에 마우스를 올리면 설명, 더블클릭하면 기본값). 🧬 변형 / 🎞️ 변형 8개 / ↩ 되돌리기(Ctrl+Z).
2. **AI·학습** 탭 — AI로 생성하거나 참고 음원에서 배우기(아래).
3. **저장·내보내기** — 왼쪽에서 프로젝트(게임)를 만들고 저장 → 라이브러리에서 `이름.wav`로 **원하는 폴더(예: Unity `Assets\Audio\SFX`)에 내보내기** 또는 ZIP. 출력은 모노 16bit WAV(22.05/44.1/48kHz), 들리지 않는 꼬리는 자동으로 잘라내고 -1 dBFS로 맞춥니다.

## 🎬 고퀄리티 합성 프리셋
검 휘두르기 · 검 부딪힘 · 검 베기 피격 · 묵직한 타격 · 피격 · **권총 · 리볼버 · 소총 · 샷건(+펌프) · 기관총 연사 · 저격총(+볼트) · 소음기 권총 · 탄피 튕김 · 장전/슬라이드** · 대형/소형 폭발.

총기는 종류마다 실제 음향 차이를 반영해 따로 설계했습니다(권총=짧은 크랙, 리볼버=낮고 긴 쿵, 소총=초음속 스냅+먼 메아리, 샷건=넓은 저역 폭음+펌프, 소음기=먹먹한 퍼프+슬라이드…).
`tools/check_guns.py`가 이를 수치로 점검합니다(크랙 밝기·저음 무게·꼬리 길이·발 수 순서, 총기 간 거리가 같은 총기의 변형끼리의 거리보다 큰지 — 현재 약 2.7배).
합성 엔진: 밴드패스(공진), 금속 비조화 배음, **룸 임펄스 응답 컨볼루션 리버브**, **어택 있는 컴프레서**, 레이어 반복(연사·탄피 튕김, 발마다 새 노이즈·타이밍 흔들림), 최대 16레이어.

## 🤖 AI로 진짜 같은 효과음 — 모델 2종 선택
`AI·학습` 탭에서 **모델**을 고르고, 종류(권총·리볼버·소총·샷건·기관총·저격총·소음기·폭발·검·타격·화살·마법·천둥…)·공간(동굴/홀/야외…)·거리를 고르거나 한글로 덧붙이면 영어 영화식 프롬프트로 조립되어 후보 1~4개를 만듭니다. 결과는 **샘플 레이어**로 작업실에 보내져 합성 저음/타격 보강, 룸 잔향, 컴프레서를 얹어 다듬을 수 있습니다.

모델별 라이선스·받는 방법·용량은 위 **「AI 모델 받기」** 표를 보세요. 앱에서는 모델 이름 옆에 `상업 이용 가능` / `⚠ 비상업 전용`이 항상 함께 표시됩니다.

### ⚠ 비상업 모델 결과의 자동 표시
AudioLDM2로 만든 샘플에는 `비상업` 표시가 붙고, **그 샘플을 한 겹이라도 쓴 효과음은 자동으로 `⚠ 비상업`** 으로 저장됩니다(합성과 겹쳐도 유지). 라이브러리 목록에 배지가 보이고, **폴더로 내보낼 때 몇 개가 포함됐는지 경고**합니다. 같은 AI 샘플을 파일로 받아 다시 올려도 표시는 유지됩니다.
이 표시는 **실수로 섞이는 것을 막는 안전장치**이지, 일부러 파일을 편집·재녹음해서 숨기는 것까지 막지는 못합니다. 출시용 프로젝트에는 AudioLDM2 결과를 아예 쓰지 않는 것이 안전합니다.

**엔진 버전(중요)**: AudioLDM2 파이프라인이 최신 transformers 와 맞지 않아 `engine/sao/venv` 는 `diffusers 0.35`, `transformers 4.49`, `huggingface_hub 0.36` 으로 고정되어 있습니다(`setup_ai.bat` 에 반영). 함부로 업그레이드하지 마세요.
쓰지 않을 땐 `⏻ AI 끄기` 로 VRAM(약 4GB)을 돌려줍니다. 앱이 강제 종료돼도 워커는 스스로 종료합니다.

## 🎓 참고 음원에서 배우기
가진 소리(직접 녹음·구매한 라이브러리·AI 생성물)를 넣으면 에너지 곡선·스펙트럼·저음 피치 하강·잔향(RT60)을 분석하고, 합성 결과와의 로그 스펙트로그램·에너지 거리를 줄이는 방향으로 파라미터를 반복 조정합니다(10~50초).
- 결과는 작업실에서 계속 다듬을 수 있고, **⭐ 내 프리셋**으로 저장됩니다. 같은 그룹 이름으로 여러 개 배우면 `그룹 무작위` 버튼으로 매번 조금씩 다른 소리를 뽑습니다.
- **원본 조각도 레이어로** — 맞춘 합성 위에 원본 녹음을 겹칩니다(가장 사실적).
- 이것은 파형 복제가 아니라 **에너지 곡선·스펙트럼 모양 맞추기**입니다. 신경망 학습이 아니라 분석 기반 최적화이므로, 디테일은 샘플 레이어와 함께 쓸 때 가장 좋습니다.
- ⚠ 사용 권한이 없는 음원(원작 게임 음원 등)은 넣지 마세요. 결과가 원본과 닮게 만들어집니다.

## 알려진 한계
- **합성 소리는 실제 녹음과 같지 않습니다.** 고퀄리티 프리셋은 게임에서 충분히 쓸 수 있게 층층이 쌓았지만, 진짜 총기·Foley 녹음의 미세한 질감은 AI 생성/샘플 레이어와 함께 쓸 때 나옵니다.
- **AI 생성 품질은 이 프로그램이 아니라 모델에 달려 있습니다.** 실측: AudioLDM2 권총은 34ms 크랙 뒤 깨끗이 감쇠해 총성의 형태는 나오지만 8kHz 위 고음이 없고, 폭발은 감쇠 없는 웅웅거림에 그쳤습니다. 그래서 합성 크랙/저음 보강 레이어와 함께 쓰는 것을 권합니다. 후보를 여러 개 뽑아 고르세요. 이 앱은 결과를 모노로 합쳐 씁니다.
- 출력은 모노입니다(3D 위치 재생용 게임 엔진 관례).
- 화면 언어는 한국어/English.
