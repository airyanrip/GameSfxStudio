프로젝트

    프로젝트는 게임 하나(또는 효과음 묶음)입니다. 만든 소리를 저장하고 한꺼번에 내보낼 수 있어요.

    1. 시작할 소리 고르기

    예: "큰 폭발음", "짧은 동전 소리", "동굴 속 물방울", "heavy sword swing"

    35%

    2. 듣고 확인하기

    변형 후보

    마음에 드는 것을 골라 편집하거나 바로 저장하세요. 발걸음·타격처럼 같은 소리를 여러 벌 만들 때 좋아요.

    3. 소리 다듬기 — 레이어

    효과음은 여러 소리 층(레이어)을 겹친 것입니다. 예: 폭발 = 낮은 울림 + 노이즈 + 타격음.

    4. 전체 마무리 (마스터)

    🤖 AI로 진짜 같은 효과음 만들기

    고급: 영어 프롬프트 직접 쓰기

    비워두면 위에서 고른 종류·공간·거리·설명으로 자동 조립합니다.

    🎓 참고 음원에서 배우기

    라이선스가 있는 소리(직접 녹음·구매한 라이브러리)를 넣으면 에너지 곡선·스펙트럼·저음·잔향을 분석해 닮은 합성 소리를 자동으로 맞춥니다. 같은 계열을 여러 개 배우면 '내 프리셋' 그룹이 되어 매번 조금씩 다른 소리를 뽑을 수 있어요. 원작 게임 음원 등 사용 권한이 없는 소리는 넣지 마세요.

      🤖 AI 모델 (Stable Audio Open)

      모델을 골라 내려받으세요. 내려받은 모델은 AI 탭에서 선택해 씁니다. 두 모델은 라이선스가 다릅니다.

      Stable Audio Open: ① 위 링크에서 HuggingFace 무료 계정으로 로그인해 라이선스에 동의 → ② Settings › Access Tokens 에서 Read 토큰 생성 → ③ 아래에 붙여넣고 내려받기. 토큰은 저장되지 않습니다.
